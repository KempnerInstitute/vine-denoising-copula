# Paired replication of the existing TC structural control

Written 2026-10-19, before the run, in the authors' paper workspace (protocol commit c9a9ae0).

Question: how precisely can the current checkpoint's TC error be compared with
first-tree KSG on the existing Gaussian AR(1) benchmark, and what is their
deployment time when measured sequentially in the same allocation?

Fixed before observing the new datasets:

- Primary setting only: d=50, n=5000, rho=0.7, 50 independently generated datasets.
  Seed i is generated by NumPy SeedSequence([20261019, 50, i]). No adaptive stopping,
  checkpoint selection, tuning, or exclusion of unfavorable datasets.
- Reuse the paper's released checkpoint, SHA256
  `8a1b71ad6d2012ed344b22a743a96e667d32a2ab54ade4444686e375e91f5c0f`,
  with its raw model weights. Library pin: `67c5b1bc6311214695d4c7fc044ea06546324906`.
- VDC: greedy D-vine, first tree only, 64 grid, checkpoint-configured projection
  iterations, batches of 256, bilinear h-functions, historical execution
  (`fast_fit=False`), float32, matrix TF32 off, convolution TF32 on.
  Preserve the benchmark's 25% evaluation split: 3750 fit / 1250 evaluation rows.
- KSG: k=5 on each of the 49 known adjacent pairs, the same 5000 generated rows,
  existing nonnegative clipping and jitter scheme. This uses the original KSG
  protocol's full sample budget; it does not impose VDC's fit/evaluation split.
  Record VDC's learned order and whether it recovers the known chain; do not discard
  a dataset if it fails. If an order differs, also compute KSG on VDC's exact edge
  set as a secondary structural diagnostic.
- First replay the three historical d=50 datasets. Save their outputs separately.
  KSG must match the archived estimates to 1e-10 nats, VDC to 0.001 nats. A failed
  qualification stops the fresh run for diagnosis; it is not silently relabelled
  a successful replay. Qualification datasets never enter the 50-dataset analysis.
- Primary contrast: paired mean absolute error difference, VDC minus KSG (positive
  favors KSG), with a 95% percentile bootstrap CI over datasets, 10000 resamples,
  fixed seed 20261019. Also report each method's MAE, RMSE, signed bias and the
  corresponding paired squared-error contrast. Absolute error of the mean TC is
  not substituted for MAE. Inconclusive intervals remain inconclusive; this does
  not guarantee a detectable difference or establish universal equivalence.
- One CPU thread per estimator; VDC additionally uses one GPU. Warm both methods
  before timing, alternate method order, synchronize GPU boundaries, exclude
  model loading and data generation. VDC time includes structure selection, fitting
  and held-out evaluation. Report median times and paired timing ratios with
  hardware details; these are deployment measurements, not compute-budget parity.
- Store every dataset hash, seed, split hash, fitted order, edge estimates, held-out
  VDC log densities, timing, package versions, source/checkpoint hashes and device.
  Outputs go to a new netscratch directory; retain the final evidence in durable
  storage and commit concise results before any manuscript update.
