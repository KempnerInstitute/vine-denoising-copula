# VDC library scope

Follow Houman's global agent rules. This repository owns reusable VDC algorithms,
training and inference, data/model download tools, library tests, API documentation
and usage examples. Paper plots, manuscript builds, table generators, experimental
protocols, saved paper results, research notes and site-specific job launchers
belong in the companion paper repository (`drafts/` in the author's workspace;
https://github.com/houman1359/diffusion-vine-copula, branch camera-ready).

Do not bring paper-only files back into this library. Link to the companion and
pin the library revision from paper workflows. Keep runtime/numerical changes
separate from repository moves and preserve historical release tags.
