# Repository maintenance

This repository owns reusable VDC algorithms, training, inference, downloads,
tests, documentation and examples. Keep changes focused and follow
`CONTRIBUTING.md`.

`projects/neurips2026/` contains selected portable experiment runners,
configurations, reference results and reproduction instructions. These import
VDC and never vendor its runtime. Manuscript builds, authoritative figure/table
generators, historical cluster launchers and internal research records are
maintained separately. A curated figure archive is attached to the public release.

Keep numerical changes separate from organization work. Preserve scientific
source pins, model hashes and historical tags. Do not add private paths,
scheduler accounts, credentials or internal notes to public projects or assets.
