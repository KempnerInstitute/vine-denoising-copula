# VDC library and public projects

Follow Houman's global rules. This repository owns reusable VDC algorithms,
training, inference, downloads, tests, documentation and examples.

Houman approved `projects/neurips2026/` as the maintained public home of the
paper's selected portable experiment runners, configurations, reference results
and reproduction instructions. These import VDC; they never vendor its runtime.
Keep numerical changes separate from release organization and retain source pins.

The private companion `drafts/` owns manuscript builds, authoritative figure/table
generators, research records and historical cluster launchers. A curated, verified
figure archive is attached to the public library release. Do not copy the private
workspace, personal storage paths, scheduler accounts or internal notes into public
projects or release assets. Preserve all historical tags.
