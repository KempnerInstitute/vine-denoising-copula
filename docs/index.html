VDC · Python library · NeurIPS 2026

Vine Denoising Copula

One pretrained network estimates every pair-copula of a vine. VDC maps the empirical histogram of each edge to a copula density grid in a single forward pass, projects it to uniform marginals, and plugs it into standard vine recursion for likelihoods, sampling and information analysis.
